PROORGANIC — исправление анимации кота

Что меняется
============
Старая анимация была scrub-анимацией: положение кота напрямую зависело от положения скролла.
Поэтому при остановке прокрутки кот зависал в произвольной фазе прыжка.

Новая версия:
- скролл только ЗАПУСКАЕТ прыжок;
- сам прыжок после запуска проигрывается до конца независимо от прокрутки;
- кот не остаётся висеть в воздухе;
- контейнер не режет кота;
- на мобильном траектория ниже и короче;
- покадровая смена во время прыжка отключена: используется один целый кадр, а движение создаёт траектория.

Как применить
=============
Вариант 1:
1. Положите PATCH_CAT.bat и patch_cat.py рядом с HTML v14.1.
2. Дважды кликните PATCH_CAT.bat.
3. Рядом появится новый файл v14.2.

Вариант 2:
Перетащите HTML v14.1 мышью прямо на PATCH_CAT.bat.

Исходный HTML не перезаписывается.
