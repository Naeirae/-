PROORGANIC v15 — прототип

Что изменено относительно v14/v14.1:
- верхняя навигация теперь построена по профессиональным вопросам из анкеты;
- каждый раздел отвечает по схеме: короткий ответ → доказательства → граница данных → следующий шаг;
- заголовки несут смысл и читаются как конспект;
- цифры 51 / 50 / 20 / 55+ кликабельны и объясняют, что именно посчитано и чего число не доказывает;
- маршруты пользователя не склеены в фиктивную воронку;
- прыжок кота больше не зависит от прогресса скролла: IntersectionObserver только запускает событие, дальше CSS-анимация доигрывается сама;
- на мобильном у кота отдельная короткая траектория;
- структура остаётся понятной без анимации.

Как открыть:
1. Распаковать ZIP.
2. Открыть PROORGANIC_v15.html в Chrome/Edge.
3. Интернет для самой страницы не нужен; внешние ссылки открываются отдельно.

Основание:
- кандидатская структура и текст PROORGANIC;
- вопросы анкеты;
- визуальный язык v14/v14.1;
- принципы смысловой структуры: самостоятельные модули, содержательные заголовки, одна мысль — один блок, явные границы вывода.
