PROORGANIC — патч прыжка кота

Запуск
------
1. Распаковать ZIP.
2. Лучше положить APPLY_CAT_FIX.bat и patch_cat.py рядом с исходным:
   PROORGANIC — прототип сайта — v14 — один файл.html
3. Дважды нажать APPLY_CAT_FIX.bat.

Патч не перезаписывает исходник.
Он создаёт:
PROORGANIC — прототип сайта — v14.2 — кот без зависания.html

Что меняется
------------
Старый код вычислял X/Y кота прямо из текущего прогресса прокрутки.
Поэтому остановка скролла останавливала кота в воздухе.

Теперь:
- прокрутка лишь один раз запускает событие;
- прыжок доигрывается сам за ~1,1 секунды;
- траектория не зависит от остановки скролла;
- покадровое переключение старых кадров во время прыжка выключено;
- движение создаётся дугой, наклоном и squash/stretch;
- на мобильном траектория короче;
- контейнер дорожки больше не режет кота.

Остальной сайт патч не меняет.
